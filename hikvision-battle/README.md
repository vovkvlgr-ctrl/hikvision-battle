# Hikvision Battle

Гра Viatec Corporate Academy. Сторінка розміщується на GitHub Pages, дані зберігаються у Firebase (проєкт `sales-pool`).

## Що в папці

| Файл | Призначення |
|---|---|
| `index.html` | уся гра: пульт організатора, екран команди, табло, рейтинг, демо |
| `vendor/` | бібліотеки Firebase і Excel-імпорту (без зовнішніх CDN) |
| `firestore.rules` | правила доступу до бази; вставляються в консоль Firebase |

## Запуск (один раз)

1. **Правила бази.** Firebase → Firestore Database → вкладка *Rules* → замінити весь текст вмістом `firestore.rules` → *Publish*.
2. **Сторінка.** GitHub → новий публічний репозиторій `hikvision-battle` → *Add file → Upload files* → перетягнути `index.html`, `README.md`, `firestore.rules` і папку `vendor` → *Commit changes*.
3. **Публікація.** Репозиторій → *Settings → Pages* → Source: *Deploy from a branch*, Branch: `main`, папка `/ (root)` → *Save*. За 1–2 хвилини гра буде за адресою `https://vovkvlgr-ctrl.github.io/hikvision-battle/`.
4. **Домен для входу.** Firebase → Authentication → Settings → Authorized domains → `vovkvlgr-ctrl.github.io` (якщо ще не додано).

## Як заходять

- **Організатор:** відкриває сторінку → «Вхід організатора» → Google-акаунт `vovkvlgr@gmail.com`. Щоб додати ще організатора, допишіть його пошту в `OWNERS` в `index.html` **і** в список у `firestore.rules`.
- **Команди:** лише посилання + код із листа. Без акаунтів і реєстрації. Один код = одна гра = один пристрій (діє перший вхід; організатор може дозволити інший пристрій).
- **Глядачі / CEO / трансляція в Teams:** те саме посилання, вкладка «Табло».

## Захист

- Налаштування, ігри, питання, коди змінює лише організатор (перевіряє сама база).
- Коди у відкритому вигляді бачить лише організатор; у базі для команд лежать тільки ключі, які відкриваються конкретним кодом.
- Вхід у гру без дійсного коду база відхиляє.
- Кожен пристрій пише лише власні відповіді.
- Демо-симуляція працює в браузері й нічого не пише в базу; пряме посилання на демо: `…/hikvision-battle/#demo`.
